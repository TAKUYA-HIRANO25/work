## 個人作品を特に見てください
### 個人作品
制作期間　2025年10月～2026年06月  
制作時間　650時間  
ジャンル　3Dのシューティングゲーム  
ライブラリ　DirectX  
フレームワーク　自作エンジン  
作品紹介　正面の敵を倒すとクリアのシューティングゲームです。この作品はDirectXをベースにした自作エンジンから作りました。敵の行動などをstateで管理し、行動ロジック(EnemyState)とデータ管理(Enemy)の責務が明確に分離される。 これにより、パラメータ変更時の影響範囲が最小化され、 状態クラスが軽量化されて可読性が向上し、 状態追加やデバッグが容易になる設計にしています。

### チーム制作
制作期間　2025年02月～2025年06月  
制作時間　250時間  
ジャンル　箱庭脱出ゲーム  
ライブラリ　DirectX  
フレームワーク　チームメンバーの作った自作エンジン  
作品紹介　ステージに配置されている旗に触れることでクリアになる脱出ゲームです。担当した個所はplayerの移動とジャンプそれに追従するカメラとstageSelectを作りました。
特に曹宇刺していて違和感のない操作感覚に力を入れました。
